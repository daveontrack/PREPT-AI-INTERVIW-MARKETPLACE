# Dataset intake layout

See `../DATASET.md` for the full strategy, consent requirements and labeling
rules. Only templates live in git — raw videos and landmark arrays are
access-controlled and git-ignored.

```
data/
├── raw/                  # {signer_id}/{clip_id}.mp4        (git-ignored)
├── landmarks/            # raw landmark .npy per clip       (git-ignored)
├── annotations/
│   ├── annotations.csv   # the canonical annotation table
│   └── TEMPLATE.csv      # header + example row (placeholder ids)
└── splits/               # generated by training/split_by_signer.py (git-ignored)
```

`annotations.csv` columns:

| column | meaning |
| --- | --- |
| `clip_id` | unique id, matches the raw filename |
| `signer_id` | anonymized signer id (never a real name) |
| `gloss` | verified EthSL gloss from `models/vocabulary.txt` |
| `consent_id` | id of the signed consent record covering this clip |
| `notes` | annotation disputes, recapture info |

Generate the signer-independent splits:

```bash
python training/split_by_signer.py \
  --annotations data/annotations/annotations.csv \
  --out data/splits --seed 42 \
  --vocabulary models/vocabulary.txt
```
